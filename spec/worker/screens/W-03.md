# W-03 — Worker sign-in (دخول المندوب)

Author: Thinker (Agent 1)
Status: **Draft** (status is changed only by the orchestrator in `/spec/worker/worker-map.md`)
Governing documents: `/CLAUDE.md` locked decision 7; `/spec/worker/worker-map.md` §4 decisions 3, 4, 5, 13, 16, 17; `/spec/staff/screens/S-03.md` — the desk sign-in this screen is built from: §5.2 (the PIN outcomes), §5.4 (arming audio), §5.6 (variant B), §7.1 (PIN rules), §7.2 (field messages); `/spec/staff/staff-map.md` §4 decisions 2, 3, 22 and Amendment A2 decisions 28, 31; `/spec/screens/G-04.md` §7.1 (digit conversion).

Conventions reused verbatim: Western digits 0–9; Arabic-Indic (٠–٩) and Extended Arabic-Indic (۰–۹) digits converted to 0–9 as typed; 44 × 44 px minimum tap areas; the 300 ms debounce; zoom never disabled; no toast.

**What differs from the desk's S-03, and why.** Three things. (1) It accepts **worker** PINs only, and says so when a supervisor PIN is typed. (2) Signing in **starts the worker's shift**: from that moment the desk can assign orders to this phone, and the screen says so before the PIN is typed. (3) It has **no queue line and no chime**: a signed-out worker has no orders coming to this phone, because the desk cannot assign to a worker who is off shift.

---

## 1. ID and name

- **ID:** W-03
- **Name:** دخول المندوب / Worker sign-in
- **Type:** Full worker screen with its own URL (example: `…/worker/sign-in`). The worker URL on a phone with no live worker session opens it; the sign-in URL opened with a live worker session goes to W-01.
- **Variants:** **A — the phone is linked to the hotel** (PIN field); **B — the phone is not linked** (S-03 variant B's block, no way forward; worker-map §4 decision 16).
- **Language:** Arabic (RTL) on first open; the header toggle switches to English in place; saved as the worker app's language, shared with W-01 and separate from the desk's.

---

## 2. Purpose

Name the worker with a 4-digit PIN and put them on shift, so the desk can send orders to this phone.

---

## 3. Entry and exit points

### 3.1 Entry

| From | Trigger | What W-03 shows | Return target |
|---|---|---|---|
| The worker URL, or the sign-in URL, on a phone with no live worker session | Browser load or reload | Variant A with an empty, focused PIN field, C02 hidden — or variant B when the phone holds no hotel link | None |
| W-01 | "إنهاء الوردية / End shift" confirmed by the system | Variant A, empty focused field, C02 hidden | None |
| W-01 | The shift was found ended (12 hours, or ended on another phone) | Variant A, empty focused field, **C02 shown** | W-01 at its scroll position |
| W-02 | The shift was found ended while W-02 was open | Variant A, empty focused field, **C02 shown** | W-02 for that order |
| WM-01 (via W-02) | The shift was found ended while WM-01 was open and nothing was in flight | Same as the row above | W-02 for that order |

Arrival from W-01 or W-02 is an in-page navigation, never a full page load, so audio stays armed.

### 3.2 Exit

| Action | Destination |
|---|---|
| The 4th digit is entered and it is a correct **worker** PIN | The shift starts, the worker session is written, and the phone goes to the return target, or to **W-01** at the top when there is none. In-page, within 100 ms of the response |
| The 4th digit is entered and the PIN is wrong, belongs to a supervisor, the phone is locked out, or the request failed | Stays on W-03 with the matching C05 message (§7.2) |
| The sign-in request answers that the phone is not linked | Stays on W-03, now in variant B |
| Tap the language toggle (B01) | Stays; re-rendered in the other language; typed digits kept |
| Browser back | Leaves the worker app; W-03 has no back arrow |

## 5. Content

### 5.0 What W-03 reads, writes, and never touches

W-03 **reads** the phone's hotel link, the worker app's saved language, the return target (page memory only), and the answer to a sign-in request. It **writes**, on a correct worker PIN only: the worker session on the phone (member identity, name, and the device-clock time of the successful response) — kept apart from the desk's session (worker-map §4 decision 3) — and, in the system, the start of the worker's shift. It sends one kind of request: sign-in.

W-03 **never**: shows a list of staff names or lets anyone pick a name; shows any order content, room number or count; plays a sound; stores the PIN after the request is sent; signs the desk in or out; offers a way to link the phone.

### 5.1 Header

Title at the start edge, language toggle at the end edge. No back arrow, no sound toggle (it is on W-01).

### 5.2 The PIN, and signing in

Steps 1–4 are S-03 §5.2 steps 1–4, unchanged: the field is empty and focused on arrival; each digit fills a cell as a dot; the 4th digit sends the request at once, disabling F01, closing the keypad and showing C06 "جارٍ التحقق… / Checking…"; the timeout is **15 seconds**.

**Outcomes — exactly six:**

| Response | What W-03 does |
|---|---|
| **Correct worker PIN** — the system returns a member whose role is worker | Starts the shift in the system, writes the worker session, arms audio (§5.4), and navigates to the return target or to W-01 (§3.2). Nothing is drawn in between |
| **Supervisor PIN** — the PIN is correct but the member's role is supervisor | Nothing is written: no worker session, no shift, and the desk's session is untouched. F01 cleared, re-enabled, focused; C05 "هذا رمز مشرف — ادخل من جهاز مكتب الروم سيرفس / This is a supervisor PIN — sign in on the room service desk device". Counts as a failed attempt toward the lockout (§7.1) |
| **Wrong PIN** | F01 cleared, re-enabled, focused; C05 "رمز الدخول غير صحيح — أعد إدخاله / Wrong PIN — enter it again" |
| **Locked out** — 5 consecutive failed attempts on this phone | F01 cleared and disabled for **60 seconds**; C05 "محاولات خاطئة كثيرة — انتظر دقيقة ثم حاول مرة أخرى / Too many wrong attempts — wait one minute, then try again"; no countdown; at 60 seconds F01 is enabled and focused and C05 hidden |
| **Phone not linked** | Variant B for the rest of this page load |
| **Failed** — not sent, dropped, no answer in 15 seconds, unreadable | F01 cleared, re-enabled, focused; C05 "تعذّر الوصول إلى النظام — تحقّق من الشبكة ثم أعد إدخال الرمز / Could not reach the system — check the network, then enter the PIN again". No shift is started |

The lockout is counted by the system, not the phone (S-03 §5.2 step 6).

### 5.3 Where a correct PIN leads, and the shift

- **No return target:** W-01, top of the list, whose first response is its chime baseline.
- **Return target W-01 or W-02:** that screen, re-requested. The return target lives in page memory only; a reload on W-03 drops it.
- **A different worker** may sign in at a return target. W-01 and W-02 then show that worker's orders; an order of the previous worker opened as the return target shows W-02's error state (W-02 §6.3 trigger 4), because it is not theirs.
- **The shift and the session** last until "إنهاء الوردية / End shift" on W-01 (confirmed by the system) or **12 hours** after the successful sign-in response, whichever is first (worker-map §4 decision 4). They survive reloads and closing the tab. There is no idle lock.
- **Signing in when this worker is already on shift** (for example on a second phone, worker-map §4 decision 5) keeps the existing shift start: the shift does not restart and its 12 hours are not extended. The phone's session starts now, and it ends with the shift.

### 5.4 Arming audio

S-03 §5.4 rules 1–3, unchanged: any touch or key press on W-03 arms audio, typing four digits always does, and W-03 → W-01 is an in-page navigation, so W-01 starts with a working chime. W-03 itself plays nothing and shows no sound line.

### 5.5 Variant B — the phone is not linked

S-03 §5.6, unchanged, with C08's copy: decided from the phone on the first frame, or from an explicit "not linked" answer — never from a failed request. Header and C08 only; no request, no sound, no way forward. The link is not deleted; a reload checks again.

### 5.6 What is deliberately not on this screen

- No "Sign in" button (the 4th digit submits), no name picker, no password, no "remember me".
- No queue line, no count of orders, no chime (see the preamble).
- No PIN reset: C07 names the supervisor.
- No back arrow, no toast, no modal.

No loading layout on arrival: variant A or B is decided on the first frame. While the sign-in request is in flight: F01 disabled with its four dots, C06 in the message slot, keypad closed, B01 still working; at most 15 seconds.

### 6.2 Empty

The empty focused field is the arrival state of variant A; no message.

### 6.4 Success

A correct worker PIN: nothing drawn on W-03; the shift starts, the session is written, and the next screen is shown within 100 ms of the response.

## 7. Field rules

### 7.1 F01 — PIN (رمز الدخول / PIN)

S-03 §7.1, unchanged in every row — required, exactly 4 digits, numeric keypad, Arabic-Indic digits converted, other characters not entered, leading zeros kept, paste rules, always masked, never stored, sent with the phone's hotel link — with one row changed:

| Rule | Decision |
|---|---|
| Accepted PINs | **Worker PINs only.** Each PIN identifies exactly one staff member; a supervisor's PIN is refused on this screen with its own message (§7.2) and counts as a failed attempt. |
| Lockout | After **5 consecutive failed attempts** on this phone — wrong PINs and supervisor PINs together — the system refuses sign-in for **60 seconds**. A correct worker PIN resets the count. |

### 7.2 Exact field messages (C05), one at a time

| Case | Arabic | English | Cleared when |
|---|---|---|---|
| Supervisor PIN | هذا رمز مشرف — ادخل من جهاز مكتب الروم سيرفس | This is a supervisor PIN — sign in on the room service desk device | The next digit is typed |
| Wrong PIN | رمز الدخول غير صحيح — أعد إدخاله | Wrong PIN — enter it again | The next digit is typed |
| Locked out | محاولات خاطئة كثيرة — انتظر دقيقة ثم حاول مرة أخرى | Too many wrong attempts — wait one minute, then try again | 60 seconds after the refusal |
| Sign-in request failed | تعذّر الوصول إلى النظام — تحقّق من الشبكة ثم أعد إدخال الرمز | Could not reach the system — check the network, then enter the PIN again | The next digit is typed |
| Enter with fewer than 4 digits | رمز الدخول 4 أرقام — أكمل إدخاله | The PIN has 4 digits — finish entering it | The next digit is typed |
| Paste containing a non-digit | استخدم الأرقام فقط (0–9) | Use digits only (0–9) | The next digit is typed |

The last five are S-03 §7.2's wording, word for word.

### 7.3 Request bounds

- One sign-in request per 4th digit; timeout **15 seconds**; never retried automatically; never two in flight.
- It carries the PIN and the phone's hotel link; nothing about a guest.

### 7.4 Tap handling, language, sizes and accessibility

- B01 and C04 respond to a single tap with the 300 ms debounce; C04 and any cell focus F01; any touch arms audio.
- Every fixed string in the worker app's saved language; typed digits and the lockout are unaffected by a switch.
- Text sizes: C01 18 px bold; C02, C04 16 px bold; C03 16 px; C05, C06, C07 14 px; C08 20/16/14 px. **Nothing smaller than 14 px.** B01 44 × 44 px; F01 260 × 64 px. Contrast at least 4.5:1 including disabled cells. Zoom never disabled.
- Screen reader: F01 announced with C04 and its fill state "{n} من 4 أرقام / {n} of 4 digits", never the digits; C03 read before the field; C05 and C06 announced when they appear.
- Motion: none.

## 8. Acceptance criteria

Each statement is pass/fail.

1. Opening the worker URL on a linked phone with no live worker session shows W-03 with F01 empty and focused; with a live worker session it shows W-01.
2. W-03 has no back arrow, no sound toggle, no "Sign in" button, no queue line, and plays no sound.
3. C03 "بدخولك تبدأ ورديتك، ويستطيع المكتب تحويل الطلبات إليك. / Signing in starts your shift, and the desk can then send orders to you." is shown above the field.
4. Entering the 4th digit sends exactly one request, disables F01, closes the keypad and shows "جارٍ التحقق… / Checking…".
5. A correct worker PIN (for example Khalid's) starts that worker's shift — the desk's picker shows them as "في الوردية / On shift" from its next update — writes the worker session, and opens W-01 within 100 ms of the response.
6. A correct worker PIN never signs the desk in or out: a desk session in the same browser is unchanged.
7. A supervisor PIN starts no shift, writes no worker session, leaves the desk session unchanged, and shows "هذا رمز مشرف — ادخل من جهاز مكتب الروم سيرفس / This is a supervisor PIN — sign in on the room service desk device".
8. Five consecutive failed attempts, wrong PINs and supervisor PINs counted together, disable F01 for 60 seconds with the lockout message and no countdown.
9. A wrong PIN, a failed request and a short Enter show the messages of §7.2 exactly; a paste with a non-digit enters nothing and shows "استخدم الأرقام فقط (0–9) / Use digits only (0–9)".
10. Arriving because the shift was found ended shows C02 "انتهت ورديتك — أدخل رمزك لتبدأ وردية جديدة / Your shift has ended — enter your PIN to start a new shift", and a correct PIN returns to the W-01 or W-02 the worker was on; arriving any other way hides C02.
11. After a reload on W-03, a correct PIN opens W-01 at the top.
12. Signing in on a second phone while already on shift does not change the shift's start time.
13. The session and the shift end 12 hours after sign-in; the session survives a reload before then.
14. On a phone with no hotel link, W-03 shows variant B on its first frame with C08's three lines word for word as on S-03, and sends nothing.
15. The PIN is not in device storage or in the page after the request is sent, and the browser never offers to save it.
16. B01 switches every string and the direction in place, keeps typed digits, and changes the worker app's language only.
17. No text is smaller than 14 px; every tappable element is at least 44 × 44 px; pinch-zoom works; a screen reader never reads a PIN digit.
18. No toast and no modal is ever shown.

## 9. Decisions settled on this screen

1. **Worker PINs only; a supervisor PIN is named and refused, and counts toward the lockout** (§5.2, §7.1), so the screen is honest about the mistake without becoming a free PIN tester.
2. **Signing in is starting the shift, and the screen says so before the PIN is typed** (C03).
3. **No queue line and no chime on W-03**, unlike the desk's S-03 (preamble): nothing is assigned to an off-shift worker.
4. **A second sign-in during a shift does not restart it** (§5.3), so the 12-hour limit cannot be extended by signing in again on another phone.
5. **The shift-ended line and the return target** follow S-03's session-expired pattern (C02, §5.3), so re-entering four digits returns the worker to the order they were on.
6. **Variant B is S-03's, word for word** (§5.5).

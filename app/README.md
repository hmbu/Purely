# متجر الغرفة — Hotel In-Room Store

النسخة العاملة من واجهة الضيف، مبنية على المواصفة في `/spec/`.

## كيف تشغّله

افتح `index.html` في المتصفح. لا شيء غير ذلك.

لا يوجد **باك إند**، ولا خادم، ولا قاعدة بيانات، ولا خطوة بناء، ولا مكتبات
خارجية. ملفات HTML و CSS و JavaScript ثابتة تعمل من القرص مباشرةً وبدون إنترنت.

> إن أردت فتحه عبر `http://` بدل `file://` (مفيد لاختباره على الجوال):
> `python3 -m http.server 8000` من داخل هذا المجلد، ثم افتح `localhost:8000`.

## شريط العرض (Demo)

الشريط الأسود أعلى الصفحة **ليس جزءاً من المنتج**. وُجد لأن المواصفة تصف
حالات لا يستطيع الضيف إحداثها بنفسه، فبدونه لا يمكن رؤية نصفها:

| الخيار | يُظهر |
|---|---|
| فشل الكتالوج | G-08 بنسخة «إعادة المحاولة» |
| رابط غير صالح | G-08 بلا زر إعادة محاولة |
| لا اتصال / خطأ خادم | M-03 عند إرسال الطلب |
| نفاد مخزون عند الإرسال | M-04 |
| لا يوجد طلب بهذا الرقم | مسار «لم نعثر على الطلب» في M-02 |
| الحالة التالية | يحرّك الطلب: جديد ← تم القبول ← في الطريق ← تم التوصيل |
| تصفير | يمسح ذاكرة الجهاز ويعيد التحميل |

«الخادم» في `js/store.js` محاكاة داخل المتصفح تُرجع وعوداً بعد تأخير قصير.
مهلات الانتظار مختصرة للعرض، وقيمة المواصفة مكتوبة بجانب كل ثابت في تعليق.

## ما تراه على الشاشة

كل عنصر يحمل معرّفه من المواصفة في `data-el`، فيمكن مطابقة ما يعمل بجدول
العناصر مباشرةً. مثلاً في أدوات المطوّر:

```js
document.querySelector('[data-el="G-01-B04"]')   // زر «أضف» على البطاقة
document.querySelectorAll('[data-el="G-01-C07"]') // شارات «غير متوفر»
```

## ما بقي مفتوحاً

`OQ-01` في `/spec/open-questions.md`: رقم الغرفة يقبل **١–٥ أرقام** فقط. إن كان
الفندق يستخدم حروفاً أو فواصل (`A-12`)، فالبديل مكتوب هناك ويجب تطبيقه قبل
الاستخدام الحقيقي.

النسخة تخزّن الطلبات على الجهاز فقط (القرار المقفل ٤)، فمسح بيانات المتصفح
يمحو سجلّ الطلبات — وهو قيد النسخة ١، لا عطل.
